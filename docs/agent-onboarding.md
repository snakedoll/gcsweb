# 에이전트 처음 설정

이 저장소에서 AI 에이전트(Claude Code, Cursor, Codex)를 처음 쓸 때 **한 번** 아래 프롬프트를 에이전트에 그대로 붙여 넣는다. 에이전트가 이 PC의 설정과 팀 규칙 확인을 진행한다.

규칙 자체는 따로 넣지 않아도 적용된다. 에이전트는 main을 받으면 `CLAUDE.md`(Claude Code), `AGENTS.md`와 `.cursor/rules/`(Cursor·Codex)를 스스로 읽는다. 이 프롬프트는 PC마다 필요한 준비(gh 로그인, 영문이름, 감시 기준점)를 맞추는 용도다.

## 설정 프롬프트

```text
이 저장소(gcsweb)의 팀 작업 방식을 이 PC에 맞춰 설정해 줘. 아래 순서대로 진행하고, 단계마다 결과를 한두 줄로 알려 줘.

1. 커밋하지 않은 변경이 있는지 확인해 줘. 있으면 무엇인지 보여 주고 멈춰. 없으면 main을 최신으로 받아 줘.
2. CLAUDE.md 전체와 AGENTS.md를 읽고, 「작업 공유」와 「GitHub 감시」 규칙을 다섯 줄 이내로 요약해 줘.
3. gh CLI가 설치돼 있고 로그인돼 있는지 확인해 줘(gh auth status). 안 돼 있으면 설치·로그인 방법을 알려 주고 멈춰.
4. CLAUDE.local.md에 '영문이름:' 줄이 없으면 나에게 영문이름을 물어보고 추가해 줘. 이 파일은 커밋하지 않는다.
5. node scripts/github-watch.mjs 를 한 번 실행해 기준점을 잡고 결과를 보여 줘.
6. Claude Code라면 Monitor 도구로 node scripts/github-watch.mjs --loop 를 켜 줘(timeout_ms 1800000, 만료되면 다시 켠다). Claude Code가 아니면 이 단계는 건너뛰어.
7. 나에게 배정된 열린 이슈, '확인필요' 라벨이 붙은 이슈, 열린 PR 목록을 보여 줘.

앞으로 코드를 고칠 때는 CLAUDE.md 「작업 공유」대로 이슈 → 작업별 브랜치 → Draft PR 순서로 진행해. 머지, 이슈 닫기, 다른 사람 이슈·PR 수정은 하지 마.
```

## 평소에 쓰는 말

| 상황 | 에이전트에게 할 말 |
| --- | --- |
| 작업 시작 | `이슈 #번호 작업 시작해 줘` 또는 `"<할 일 설명>" 작업 시작해 줘` (Claude Code는 `/task start <설명>`) |
| 기획·디자인 답이 필요할 때 | `이 부분 기획 확인이 필요해. 이슈에 확인필요로 질문 남겨 줘: <질문>` |
| 하루 마무리 | `오늘 작업 정리해 줘. 이슈에 진행 댓글 남기고, 다 끝났으면 시험 돌린 뒤 리뷰 요청까지 해 줘` |
| 다른 사람 변경 확인 (Cursor·Codex) | `GitHub 변경 확인해 줘` (`node scripts/github-watch.mjs`) |
